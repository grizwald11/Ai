# VAYU Wholesale App

Cross-platform iOS/Android app for VAYU CBD wholesale orders, built with React Native, Expo and TypeScript.

> The product list in this repo is sample data. Pricing is not stored in the app: wholesale pricing is quoted per account after an order request.

## Quick Start

```bash
npm install
npx expo start
```

## Features

- Product catalog with category filtering
- Cart with quantity management
- Wholesale order request form with business info
- Minimum order quantities enforced

## Stack

- Expo ~50, React Native 0.73, React 18.2
- React Navigation (bottom tabs)
- TypeScript (strict mode)

## Build

```bash
npx expo build:ios
npx expo build:android
```
